Developer Playground

import { EdgeInfer } from '@edgeinfer/web';

// Initialize WebGPU engine
const engine = await EdgeInfer.init({
  backend: 'webgpu',
  modelPath: '/models/llama-3-8b-instruct-onnx'
});

// Generate text entirely on-device!
const response = await engine.generate({
  prompt: "Write a haiku about local AI",
  maxTokens: 50
});

console.log(response.text);

Architecture & How It Works

EdgeInfer bridges the gap between high-performance AI models and web accessibility.

1. Model Quantization

Large language models are quantized to INT4/INT8 formats and exported to ONNX, reducing memory footprint by 4x without significant quality loss.

2. WebGPU Acceleration

Leverages the modern WebGPU API to tap directly into the user's local graphics card (GPU) from the browser, outperforming WebGL by magnitudes.

3. Secure Execution

Inference runs strictly client-side. No user queries or prompt data are ever transmitted to a server, ensuring compliance with HIPAA, GDPR, and strict privacy laws.

Frequently Asked Questions

Is EdgeInfer a free OpenAI API alternative?

Yes. EdgeInfer is designed as a drop-in architectural replacement for cloud-based inference APIs like OpenAI, Vertex AI, or Replicate. By shifting computation to the edge (the user's device), it acts as a completely free alternative.

What models are supported?

We support a wide range of ONNX-compatible models. Popular choices include Llama 3 (8B), Mistral (7B), Phi-3, Whisper (speech-to-text), and various embedding models like BGE-M3.

Does it require installing native software?

No. EdgeInfer runs entirely within modern web browsers (Chrome, Edge, Firefox, Safari) that support WebGPU or WebGL fallback. No installations, Docker containers, or Python environments required.
